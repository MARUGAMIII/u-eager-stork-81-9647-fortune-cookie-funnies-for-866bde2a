One fortune cookie message for a software engineer (83 characters):

> Your error message will be clear, helpful, and completely unrelated to the problem.

The joke is recognition with a sting: the rule of three builds up two reassuring promises, then the third word demolishes them both. Every engineer has met the confident, useless error message. It reads like a real fortune, lands on the first read, and the funniest word sits at the very end.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (standard library only, deterministic - the same line on every run) and prints it to stdout.
